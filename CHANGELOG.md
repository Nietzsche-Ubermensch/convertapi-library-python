# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2024-01-15

### Added
- Modern Python packaging with `pyproject.toml` (PEP 621)
- Comprehensive documentation (CONTRIBUTING.md, CODE_OF_CONDUCT.md, SECURITY.md)
- Type hints to all public functions and classes
- Docstrings for better code documentation
- Error handling documentation and examples
- Troubleshooting/FAQ section in README
- GitHub issue and pull request templates
- CI/CD enhancements with linting, type checking, and code coverage
- Dependabot configuration for automated dependency updates

### Changed
- Updated minimum Python version from 3.3 to 3.8
- Improved README with table of contents and better organization
- Replaced wildcard imports with explicit imports
- Updated setup.py with proper PyPI classifiers
- Enhanced CI workflow with modern tooling (pytest, mypy, ruff)

### Fixed
- Fixed terminology from "gem" to "library" in documentation
- Updated repository links to point to current fork
